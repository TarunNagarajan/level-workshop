# Passport desk artwork

Built-in image generation was used for all four raster assets. The approved object-only reference supplied the visual style. No people, hands, portraits or silhouettes appear in the selected assets. Sharp only trims transparent margins, resizes, and encodes WebP; it preserves generated alpha. Functional names, dates, signatures and stamps are rendered in the interface so they remain readable and editable.

The source assets are `static/reference-assets/background.webp`, `passport-cover.webp`, `open-book.webp`, and `stamp.webp`. Vite copies them to the same URL paths under `/reference-assets/`. The combined transfer size is about 944 KB before HTTP caching.
