# Route-decoder instruction and delivery ablation

**Locked before calls, 3 October 2026.** The original eight-world chain failed because B included both a wait and the correct route after A's valid handoff. A later state-compiled package fixed B's whole-label format in 8/8 worlds, but changed decision wording and delivery together. This ablation targets that B transition alone. It does not rewrite either saved run.

Use the same eight worlds and each original run's saved, parseable A color as the authentic source. Test two B instruction packages crossed with two channels for the same literal message `Application handoff from A: SEAL_COLOR=<color>.` The **original** instruction is the exact B system text from `compileChainRequest`. The **conditional** instruction keeps the private codebook but explicitly says what to return for no handoff, amber handoff, and cobalt handoff, with one complete label and no combined wait/answer. Each instruction receives the identical shared task and final `Perform your role.` query. Insert the handoff message either as a user message or as a second system message at the same position. The only within-instruction/channel change is that message's role. Include the earlier **compiled-state** request as a fifth, contemporaneous after-handoff reference, with its own before-handoff reference. All arms use the same saved A source, model, and output parser.

There are 24 before calls: original, conditional, and compiled-state prompts over eight worlds. The original and conditional before requests are shared across their user/system arms because no handoff message exists. There are 40 after calls: original-user, original-system, conditional-user, conditional-system, and compiled-state over eight worlds. Shuffle all 64 jobs with fixed seed 1203. The primary outcomes are exact `Awaiting color.` before sharing and a whole-label correct route after sharing. Report exact lowercase format separately. A mixed wait-and-route answer fails whole-label scoring even if it contains the right route. Count provider errors/no-responses separately. This is a small prompt ablation over an exhaustive authored eight-world factorial, not an estimate of general model performance.

Bind each after handoff to the saved A observation through a signed artifact in the request compiler. Store request bodies, hashes, source IDs, raw replies, order, timing, and errors. Keep GPT-OSS 20B, temperature 0.3, low reasoning, 2048 completion tokens, at least 2.6 seconds between calls, one retry for the known tool-call HTTP 400, and stop on 429 for same-manifest resumption. No prompt or parser changes after observing output.
